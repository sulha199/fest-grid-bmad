- (capability) CAP-13 Deep Code Review Gate: when the lightweight Reviewer verdict is APPROVE, a second, deeper adversarial review (three parallel lenses -- correctness, edge-case, acceptance-criteria coverage) runs against the finished story's diff before GitCheckpoint fires. An unflagged response just unblocks the current story as before
