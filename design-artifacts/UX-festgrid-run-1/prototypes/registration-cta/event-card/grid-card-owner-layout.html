Yang saya ubah dari desain Anda

  • Ukuran teks: 10px hanya di kartu sempit; 12px dari kartu 145px ke atas (layar 340px dan lebih lebar), lewat container query pada kartu (pola yang sama dengan kartu live). Judul (12px) dan lokasi (11px) tidak diubah.
  • Label: "hari terakhir" menggantikan "berakhir hari ini".
  • Baris footer: saya tambah gap-[1em] antara slot kiri dan tipe event, dan slot kiri tidak boleh membungkus (whitespace-nowrap). Hasil tes Inggris: tanpa itu "8:00 AM" dan "+2 schedules" membungkus jadi dua baris, dan "8:00 AM" menempel ke "Competition".
  • Salinan Inggris "+2 more": saya ganti dari "+2 schedules" karena dengan teks 12px label itu (sekitar 95px) hampir tidak menyisakan tempat untuk tipe event di kartu 149-159px. Ini keputusan teks, silakan ganti.
  • Warna badge status: emerald-600 dan amber-700 (bukan emerald-500/95 dan orange-500), karena putih di atas emerald-500 hanya sekitar 2,5:1. Warna teks hijau: emerald-700 (bukan 600).
  • Selain itu semua class spasi, radius, dan ukuran mengikuti file Anda. Mode gelap belum digambar (desain Anda terang saja).

Dampak ke aplikasi

  • Halaman live sekarang memakai padding halaman 16px dan jarak antar kolom 8px. Desain Anda memakai 14px dan 14px, jadi grid dan padding halaman daftar harus diubah supaya sama.
  • Label baru perlu kunci i18n di id.json dan en.json ("hari terakhir" / "Last day"). Kunci yang ada, statusEndsToday, bernilai "Berakhir Hari Ini" / "Ends Today".
  • Performer (schedules.performers) ada di data tetapi belum diambil query list. Jam mulai dan "+N jadwal" sudah ada di query list.
