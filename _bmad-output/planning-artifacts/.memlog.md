- (decision) AD-8 new rule 4 (mutation contract): soft-delete mutations take an explicit direction argument via a shared enum SoftDeleteAction { DELETE, RESTORE }, argument name 'action' (e.g. deleteUserLocation(id: ID!, action: SoftDeleteAction!): UserLocation), returning the affected row's own type so the client syncs its cache from the response rather than a bare boolean.
