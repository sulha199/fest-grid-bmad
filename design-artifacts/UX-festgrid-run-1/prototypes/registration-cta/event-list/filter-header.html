1. Coba langsung: scroll ke bawah dan ke atas

Aturan collapse sama dengan hook yang sudah dipakai app (useCollapseHeaderOnScroll): header menciut menjadi tombol "Tampilkan filter" setelah halaman digulir melewati tinggi header (minimal 80px); kembali ke atas membukanya lagi. Gerak collapse dan expand sekarang memakai transisi dari file Anda: panel mengecil lewat max-height ke 0 selama 0,28 dtk (cubic-bezier 0,4 / 0 / 0,2 / 1) dan memudar selama 0,22 dtk, sementara tombol muncul memudar. Mengetuk tombol membuka panel yang sama sebagai panel mengambang dengan transisi yang sama (tidak menggeser isi); panel menutup bila digulir lebih dari 32px, ketuk di luar, atau Esc. Selama dropdown terbuka, collapse ditunda. Titik indigo di tombol muncul bila ada filter aktif. Baris dropdown (Kapan saja, Tipe, Kategori, Terdekat) satu baris dan bisa digeser ke samping; coba geser di 1b.

4. Spesifikasi trigger dropdown bersama

Satu trigger untuk Waktu, Tipe, Kategori, dan Terdekat.

  • Chevron: ikon chevron-down 10px, text-muted-foreground, di kanan label; berputar 180 derajat saat terbuka. Ada di semua trigger dropdown (waktu, tipe, kategori, terdekat).
  • Ukuran: tinggi terlihat 28px (px-3.5 py-1.5 text-xs, rounded-lg) seperti file Anda; area sentuh 44px lewat after:-inset-y-2.
  • Aktif: latar dan border indigo, label memuat pilihan (waktu) atau lencana jumlah (tipe, kategori). Pilihan tunggal untuk waktu, jamak untuk tipe dan kategori.
  • Drawer: pil sebaris di bawah baris dropdown (seperti file Anda), satu terbuka pada satu waktu. Pil 26px lebih rendah dari target 44px yang dipakai di tempat lain; keputusan Anda.

5. Tombol AI dan baris filter yang bisa digeser (keputusan 2026-11-21)

  • Tombol AI pindah ke baris pencarian, di kanan kolom pencarian, tinggi 34px sama dengan kolom (area sentuh 46px). Kolom pencarian mengisi sisa lebar. Di app sekarang tombol ini ada di akhir baris dropdown dan 40px.
  • Baris dropdown (Kapan saja, Tipe, Kategori, Terdekat) satu baris dan bisa digeser ke samping, tidak membungkus lagi. Baris keluar sampai tepi layar (-mx-3.5 px-3.5) sehingga chip yang terpotong di tepi menjadi petunjuk bisa digeser. Trigger tidak mengecil (shrink-0). Padding vertikal 8px di dalam area geser menjaga area sentuh 46px (tanpa itu area sentuh tambahan terpotong oleh overflow).
  • Terdekat berupa ikon (panah yang sama dengan penunjuk jarak di kartu). Nonaktif: ikon + chevron saja, 46px lebar, nama "Terdekat" ada di aria-label dan tersembunyi secara visual. Aktif: ikon + "5 km" + chevron, dan aria-label "Terdekat: 5 km". Nama lokasi tersimpan tidak tampil di tombol (ada di panelnya). Risiko: saat nonaktif tidak ada teks sehingga kurang mudah ditemukan, sama seperti tombol AI. Terdekat hanya tampil untuk pengguna yang login.
  • "Hapus filter" berupa ikon (corong dengan tanda silang, 30px, area sentuh 46px, border seperti tombol AI) di kanan baris geser, di luar area geser, jadi selalu terlihat dan tidak menimpa chip; tampil hanya bila ada filter aktif, dan baris geser memendek sebesar lebarnya. Namanya ada di aria-label dan tooltip "Hapus filter".
  • Konsekuensi: chip terakhir tidak terlihat penuh di 390px (Terdekat terpotong), dan pengguna desktop dengan mouse perlu shift + roda atau seret di trackpad. Hal ini dapat diterima di layar sentuh; di desktop (aplikasi memakai rail dan lebar lebih besar) baris tidak meluap.

Perubahan dari file Anda dan dampak ke app

  • Padding header disamakan dengan grid (px-3.5, bukan px-4) supaya tepi pencarian lurus dengan tepi kartu. Baris dropdown satu baris yang bisa digeser horizontal (bagian 5).
  • Tombol hapus per dropdown (X di dalam trigger, ada di app sekarang) tidak dipakai: lencana jumlah plus pil "Semua tipe/kategori" dan "Hapus filter" menggantikannya. Tombol X di dalam tombol juga bermasalah untuk pembaca layar.
  • Opsi waktu "Minggu ini" menggantikan "Mendatang" (semua event ke depan). Ini perubahan perilaku, bukan hanya tampilan: nilai UPCOMING di use-temporal-filter.ts, query list, dan parameter URL ?temporal= perlu nilai baru (jangkar THIS_WEEK sudah ada di filter AI). Event yang dulu tampil di "Mendatang" tetapi lebih dari satu pekan lagi hanya terlihat di "Kapan saja".
  • Komponen bersama: saat ini tidak ada komponen dropdown bersama. Trigger Tipe, Kategori, dan Terdekat di FilterHub.tsx adalah Button variant="outline" di dalam Popover, dan tidak ada satu pun chevron di packages/ui. Toggle Hari ini | Mendatang | Semua (TemporalFilterToggle) adalah radio bersegmen. Implementasi perlu satu trigger bersama dengan chevron (bagian 4) untuk keempatnya. Kode app belum diubah (sesi perencanaan).
  • Padding header diperbaiki: pada versi sebelumnya skrip collapse ikut mencabut px-3.5 dari kontainer filter saat halaman di posisi atas, sehingga pencarian, baris dropdown, dan tab Kartu menempel ke tepi bingkai. Sekarang padding ada di lapisan sendiri yang tidak pernah diubah skrip; pencarian, dropdown, tab, dan kartu semua mulai di titik yang sama (diuji untuk keempat frame).
  • Gerak collapse dan expand mengikuti file Anda: panel mengecil lewat max-height ke 0 selama 0,28 dtk (cubic-bezier(0.4, 0, 0.2, 1)) dan memudar selama 0,22 dtk; tombol "Tampilkan filter" memudar masuk bersamaan (di file Anda tombol langsung muncul tanpa animasi). Panel mengambang memakai transisi yang sama. Selain itu: konten yang tertutup tidak bisa difokus (inert dan visibility ditunda sampai selesai memudar), dan prefers-reduced-motion mematikan transisi. Saat collapse dan expand di tengah halaman, isi di bawah header ikut bergeser sepanjang transisi (sama seperti file Anda); itu sebabnya dibuat mulus.
  • Dipertahankan dari app: collapse-saat-scroll dengan panel mengambang (bukan ekspansi dalam alur seperti skrip file Anda, karena itu menggeser isi dan tinggi dokumen saat membaca), tab tampilan Kartu/Kalender, "Terdekat" dan tombol AI (bagian F8).
