# UX for festgrid
- (decision) Default Location for Subscriptions flow (EXPERIENCE.md User Flows) split into first-time-set vs edit-existing cases, matching PRD/epics.md Stories 3.3/3.3b. Edit case gets new 'Default Location Pending Review' state pattern: immediate save, Pending Review badge, moderator accept/revert. Reason: defaultLocation moved to account-level (shared across subscribers) per architecture review; old flow's step 5 wrongly associated the value with the subscription and had no moderation touchpoint.
- (event) EXPERIENCE.md updated (targeted fix, not a full UX pass). DESIGN.md unchanged -- no new component/token needed, 'Pending Review' badge reuses existing Notification/badge visual language. No other touchpoints found assuming silent/unmoderated subscription edits. Moderator-side Moderator Items UX intentionally out of scope, owned by Epic 4's existing UX coverage.
